# Restaurante Origen

Sitio web desarrollado con **HTML5, CSS3 y JavaScript** para presentar el restaurante **Origen**, ofreciendo una experiencia gastronómica elegante mediante un diseño moderno, adaptable y optimizado para la web.

---

## Descripción

Restaurante Origen es un sitio web informativo diseñado para promocionar un restaurante de alta cocina. El proyecto fue desarrollado como parte del módulo **Publicaciones de Páginas Web** del Instituto Nacional de Aprendizaje (INA).

El sitio permite a los usuarios conocer el restaurante, explorar su menú, visualizar imágenes, obtener información de contacto y disfrutar de una navegación intuitiva desde cualquier dispositivo.
